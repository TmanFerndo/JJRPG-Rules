# New Shadow Style
The New Shadow Style is a method of Jujutsu that incorporates [Simple Domain](./Simple%20Domain.md) and Sword Drawing Techniques (Iai) to enhance a sorcerer's combat capabilities. In order to learn New Shadow Style Techniques a Sorcerer must first learn [Simple Domain](./Simple%20Domain.md). In addition, many New Shadow Style Techniques require or benefit from a weapon with the **Quick Draw** feature.
